ハブ設定

行の「公開中／非公開」は押すとすぐ反映。それ以外の変更は下の「保存して反映」で確定します。

選んだ単元の設定

使い方 「公開中／非公開」は押した時点で児童の画面に反映されます（保存は不要）。それ以外の変更は「保存して反映」で確定します。
URL は各単元のデプロイ URL（末尾が /exec）。「教師ページ」はその URL に ?page=teacher を付けた先です。
「表示する学年タブ」を1つも選ばないと、全学年のタブに表示されます。児童がそのタブを見られるかは「表示と権限」で学年ごとに決めます。
「記録シート」はその単元のスプレッドシートの URL で、単元横断分析が読みます。空欄でも単元は使えます。
一覧の並び順が、児童の画面の並び順です。
名簿シートを開く↗ メールアドレスも表示
名簿の扱い このハブの roster シートが名簿の正本です。編集はシートで行います。 各単元の roster シートの A1 に =IMPORTRANGE("ハブのスプレッドシートURL","roster!A:E") を入れて参照させます（初回のみ単元側で「アクセスを許可」）。
記録・分析の対象は、メールアドレスと氏名の両方がある児童だけです。名簿にない児童や氏名が空の児童も「おためし」として全モードを使えますが、記録はされません。

過年度の名簿と個人情報

年度ごとに、児童の氏名・メールアドレスが残っている人数（全単元の記録の合計）を出します。 「消去」を押すと、その年度の記録の氏名とメールを 児童001 などに置き換えます。元に戻せません。 番号は年度の中で全単元共通です（同じ児童は、どの単元でも同じ番号）。学年・組・番号は残るので、単元の「過年度」「分析」タブの集団の統計はそのまま見られます。

実行の記録

名簿の年度保存と、消去の範囲

名簿の年度保存：毎年 4/1 の朝に、ハブと各単元の roster が roster_前年度（例 roster_2025）へ値のまま写されます。 ハブの roster は消えません。新年度の名簿は準備ができた時に roster を書き換えてください。 4/1 より前に名簿を入れ替える時は、先に「いまの名簿を前年度の名簿として保存」を押してください（4/1 の自動保存は、すでに roster_前年度 があれば何もしません）。

消去の範囲：各単元の log・mistakes・coop・coop_log・coop_save のうちその年度の行、summary のうち今の名簿にいない児童の行、 ハブの an_facts・an_support（児童を対象にした手立て）のうちその年度の行。名簿シート roster_年度 はハブ・各単元とも削除します。 今年度は消せません。summary（自己ベスト）は年度で区切られていないので、今の名簿にいる児童の行は残します。

消えないもの：手立ての内容・メモ（an_support・an_decisions）に手で書いた氏名、グループ分け シート、 そしてスプレッドシートの版の履歴（書き換える前の値が残ります）。完全に消す手順は docs/SETUP.md の「過年度」にあります。

児童が切り替えられる学年タブ

この設定について 名簿にある児童は、自分の学年のタブに加えて、ここで選んだ学年のタブを見られます（例：3年の行で「4年」を選ぶと、3年生が4年のタブも切り替えられる）。 自分の学年は外せません。名簿にない児童は全タブを見られます。

画面のタイトルと権限

単元横断分析を開ける人 単元横断分析は、この設定画面とは別に権限を持ちます。開けるのはスプレッドシートの所有者と、 config シートの an_analysts に書いた人だけです（例 a@edu.nishi.or.jp:3-1|3-2）。
