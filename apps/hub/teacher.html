ハブ設定

選んだ単元の設定

使い方 「公開中／非公開」は押した時点で児童の画面に反映されます（保存は不要）。それ以外の変更は「保存して反映」で確定します。
URL は各単元のデプロイ URL（末尾が /exec）。「教師ページ」はその URL に ?page=teacher を付けた先です。
「表示する学年タブ」を1つも選ばないと、全学年のタブに表示されます。児童がそのタブを見られるかは「表示と権限」で学年ごとに決めます。
「記録シート」はその単元のスプレッドシートの URL で、単元横断分析が読みます。空欄でも単元は使えます。
一覧の並び順が、児童の画面の並び順です。
メールアドレスも表示
名簿の扱い このハブの roster シートが名簿の正本です。編集はシートで行います。 各単元の roster シートの A1 に =IMPORTRANGE("ハブのスプレッドシートURL","roster!A:E") を入れて参照させます（初回のみ単元側で「アクセスを許可」）。
記録・分析の対象は、メールアドレスと氏名の両方がある児童だけです。名簿にない児童や氏名が空の児童も「おためし」として全モードを使えますが、記録はされません。

学年ごとに表示するタブ

この設定について 名簿にある児童は、自分の学年のタブに加えて、ここで選んだ学年のタブを見られます（例：3年の行で「4年」を選ぶと、3年生が4年のタブも切り替えられる）。 自分の学年は外せません。名簿にない児童は全タブを見られます。

全体

単元横断分析を開ける人 単元横断分析は、この設定画面とは別に権限を持ちます。開けるのはスプレッドシートの所有者と、 config シートの an_analysts に書いた人だけです（例 a@edu.nishi.or.jp:3-1|3-2）。
