# 暗算(ひき算)（中身は2けたの筆算）

児童には暗算の練習として出す。画面は筆算の形に並べ、答えは一の位から打つ。「頭の中で筆算をすればよい」という意図。

| モード | 出題例 | 範囲 | 開く条件 |
|---|---|---|---|
| 1けたの くりさがり（型K） | 16−9 | 10〜18 − 1けた、一の位から引けないもの。横書き・1欄 | なし |
| くりさがり なし（型D） | 87−52 | 答えは2けた | 1を3回 |
| くりさがり（型E） | 52−37 | ひかれる数の一の位は0でない、答えは2けた | 2を3回 |
| こたえが 1けた・0の ある かず（型F） | 52−47 ／ 60−24 | 答えが1けた／ひかれる数の一の位が0、半々 | 3を3回 |
| ぜんぶ いり | — | 型K・D・E・Fを同じ割合 | 4を3回 |

## 設計

- 2けたの問題の答えの欄は、毎回 十・一 の2つ。答えが1けたでも十の欄は出る（空欄は0）。
- 打つ順は一の位から（`f: ['一','十']`）。画面の並びは `rows` の `'_1','_0'`。
- 頭の中で位ごとに引くやり方は、くり下がりで「大きい数から小さい数を引く」誤りを生みやすいと報告されている（Beishuizen 1993, JRME 24(4)）。52−38 なら、この誤りは 26、くり下がりを忘れると 24（正しくは 14）。誤答明細で確かめる。
- 正解がそろった時点で次へ進む。誤答は欄を埋めるか「こたえあわせ」キーで確定する。
- 既定の制限時間は60秒（共通の既定と同じ）。
