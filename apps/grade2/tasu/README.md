# 暗算(たし算)（中身は2けたの筆算）

児童には暗算の練習として出す。画面は筆算の形に並べ、答えは一の位から打つ。「頭の中で筆算をすればよい」という意図。

| モード | 出題例 | 範囲 | 開く条件 |
|---|---|---|---|
| 1けたの くりあがり（型K） | 9+7 | 1けた+1けた、和10〜18。横書き・1欄 | なし |
| くりあがり なし（型A） | 34+52 | 一の位も十の位も10未満 | 1を3回 |
| くりあがり（型B） | 47+38 | 一の位でくり上がる、和99まで | 2を3回 |
| 百を こえる（型C） | 75+30 ／ 67+58 | 十の位だけ／両方でくり上がる、半々 | 3を3回 |
| ぜんぶ いり | — | 型K・A・B・Cを同じ割合 | 4を3回 |

## 設計

- 2けたの問題の答えの欄は、毎回 百・十・一 の3つ。和が2けたでも百の欄は出る（空欄は0）。欄の数が変わらないので、確定の早さから答えの大きさは漏れない。百の位があるかを決めるのも筆算の一部として残す。
- 打つ順は一の位から（`f: ['一','十','百']`）。画面の並びは `rows` の `'_2','_1','_0'` で百・十・一の順にする。
- 正解がそろった時点で次へ進む。誤答は欄を埋めるか「こたえあわせ」キーで確定する（`enterKey`）。
- くり上がりのメモのマスは置かない。
- 既定の制限時間は60秒（共通の既定と同じ）。
- 誤答明細（mistakes）は欄の順ではなく普通の数で出す（`fmtAnswer`）。
