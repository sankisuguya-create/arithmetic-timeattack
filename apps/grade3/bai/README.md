# 何倍でしょう（3年）

モードは前提スキルの依存順。型を混ぜるのは最後の「ぜんぶ」だけ。前のモードを3回で次が開く。

| モード | 対象の前提 | 型 | 答え方 |
|---|---|---|---|
| ① もとにする大きさ | 「の」の前がもとにする大きさ | A | 番号（2択） |
| ② ずに かく | 文を図に置く（テープ図／関係図を半々） | D テープ／E 関係図 | 数（Enter） |
| ③ しきを えらぶ | 何を問われているかで演算を決める | S | 番号（3択） |
| ④ なんばい けいさん | 第1・第2・第3用法を 1:1:1 | F／G／H | 数（Enter） |
| ⑤ ばいの ばい | 倍の倍＝倍×倍 | I 何倍／J a×b×c | 数（Enter） |
| ⑥ ぜんぶ | — | 全部 | 混在 |

## 記録の読み方（mistakes シート）

tag の書式：`u<用法><o|r> m<もと> k<倍>`（例 `u3r m6 k4`＝第3用法、逆順の文、もと6・倍4）

| 見る所 | 読み方 |
|---|---|
| `o` と `r` | o＝数の出てくる順が計算の順、r＝逆。r だけで誤る → 出てきた順に式を立てている（N2） |
| H の誤答が m×k×k（＝くらべる量×倍） | 「倍ならかける」（N1） |
| F・H の誤答が 和 | 倍を差とみている（N3） |
| I の誤答が a＋b | 倍の倍を足している（N5） |
| D と E | 同じ児童が片方の図だけで誤る → 図の読み方（N6） |
| S の tag `S:mul-div-add …` と答えた番号 | 何番目の式を選んだか。mul＝かけ算、add＝たし算 |

## 設計上の決まり

- **語順は①から半々で混ぜる。** そろう文だけで練習すると、出てきた順に式を立てても正解してしまう。
- **③は計算させない。** 演算の選択と計算の速さを分けて測る。式は大きい数を先に書く（÷が3年で読める形）。
  そのため③は N2（語順）を測らない。N2 は④の o/r で見る。
- **④⑤は Enter 確定。** 第1・第3用法は答えが1桁、第2用法は2桁。1桁で自動確定すると、
  かけてしまった児童の2桁目が切られて誤答の値が残らない。正しい答えは打った時点で通る。
- **図は数の大きさに比例させない。** テープの長さの比から答えが読めてしまうため。
- 数は もと・倍 とも 2〜9（くらべる量は九九の範囲）。⑤の答えは 80 以下。

## 未検証

- N1・N2 は一般の文章題（主に加減）での知見。この単元での出方は推定。
- `slow_ms` 8000 に根拠はない。文を読む時間が乗るので、実測で調整する。
- 「もとにする量＝小さいほうの数」（N4）は3年の範囲では常に正解になり、このTAでは検出できない（4年「倍の見方」で扱う）。
