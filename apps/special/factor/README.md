# 素因数分解タイムアタック

学年に属さない特殊枠。アクセントはコバルト（メニュー #245BC2／プレイ #85ADFF）。

## モード

1. 16まで：4〜16の合成数、図あり
2. 九九まで：九九に現れる合成数、図あり
3. 45まで：4〜45の合成数、図あり
4. 360まで：4〜360の合成数、図あり
5. 九九まで（図なし）：2と同じ範囲
6. 360まで（図なし）：4と同じ範囲

素数キーを選ぶと残りの数を割る。最後の素数まで入力して完了とし、1は表示せず「クリア！」を表示する。分解の順番は自由。「すうじキーせってい」で右側／左側を切り替えられる。素数キーは小さい順に横3列で下へ続き、キー領域の縦スクロールで後続の素数を選べる。キーの大・中・小も既存設定を利用する。自由入力はない。

左図は残りの数と連動し、中心に点を置かず円周に配置する。現在の式の末尾は完了まで「？」。前問の完成した式は現在の式の下に薄い正解色で残る。説明文は表示しない。

背景は720の円配置。既存の記録・ランキング・協力・背景の成長を利用する。型別集計はモードごとに分ける。途中の入力イベントを集める追加計測は未実装。研究に基づく提案は `docs/FACTORIZATION_MEASUREMENT.md` を参照。
