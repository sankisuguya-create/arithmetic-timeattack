# 円と球（3年）

モードは前提スキルの依存順。土台に近いものを先に置き、型を混ぜるのは最後の「ぜんぶ」だけ。
各モードは前のモードを3回で開く（`needs`）。

| モード | 対象の前提 | 型 | 答え方 |
|---|---|---|---|
| ① ちゅうしん・はんけい | 中心の同定／半径の定義 | A 中心はどれ／B 半径はどれ | 番号 |
| ② ちょっけい | 直径の定義 | C 直径はどれ | 番号 |
| ③ はんけい⇄ちょっけい | 半径と直径の換算 | D 半径→直径／E 直径→半径 | cm（2桁） |
| ④ きゅう | 中心を通る切り口＝最大 | F 切り口／G・H 球の半径⇄直径 | 番号／cm |
| ⑤ ならんだ まる | 並んだ図で長さをつなぐ | I 1列→よこ／J 箱→1こ分／K たてよこ | cm（2桁） |
| ⑥ ぜんぶ | — | A〜K | 混在 |

## 設計上の決まり

- **図の向きは①から毎問ランダム。** 向きを固定すると「半径は右向きの1本」「直径は横の端から端」
  という典型図への固着を練習が強める（推定）。
- **番号の問いの誤りの選択肢は、誤概念ごとに1つ。** 並びは毎問入れ替わるので、
  `tag`（例 `B:chord,rad,short,off`）に並びを残す。mistakes シートの「もんだい」と
  「こたえた値」から、どの誤りの選択肢を選んだかが読める。

  | 型 | 正答 | 誤りの選択肢（ねらう誤概念） |
  |---|---|---|
  | A | center | near / mid / edge：内側の点ならどれでも中心 |
  | B | rad | short：円周まで届かない／chord：半径と同じ長さの弦（「半分の長さ＝半径」）／off：中心以外から |
  | C | dia | hchord：中心を通らない横の弦（「横の端から端＝直径」）／rad：半径／part：円周まで届かない |
  | F | mid | up / top / down：中心を通らない切り口（「切り口はどれも同じ」） |

- **長さの答えは全部2桁（10〜99）。** 桁数が確定のタイミングとして漏れないため。
  半径を答える問いは直径を偶数に限る（小数は未習）。
- **I・J で答えがちょうど正答の半分／2倍** なら、1こ分を半径で数えている可能性（誤概念 M5）。
  I は1こ分を直径で示す問いと半径で示す問いが半々なので、両者の正答率の差で見分ける。
