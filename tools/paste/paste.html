貼り付け補助

Apps Script のエディタに貼るファイルを、貼る順と Apps Script 上の名前つきで並べます。

よみこみ中…
  1. スプレッドシートの 拡張機能 › Apps Script を開く。
  2. 上から順に「コピー」を押し、Apps Script 側の同じ名前のファイルに貼る。
  3. HTML のファイルが無ければ ファイル › ＋ › HTML で作る。拡張子は入力しない。
  4. 保存し、デプロイ › デプロイを管理 › 鉛筆 › バージョン「新バージョン」 で更新する。 新規デプロイにするとURLが変わり、児童のリンクが切れる。
  5. 教師画面の見出しに出る Core の版が、上の版と一致するか見る。
