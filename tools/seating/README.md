# 座席表ツール

名簿から座席表を作って印刷するための Google スプレッドシート用スクリプト。
算数タイムアタック本体とは独立していて、共有するコードはない。

いま入っているのは**手で並べて印刷するところまで**。
過去に同じ班・隣になっていない組を優先する自動生成は次段（下の「次にやること」）。
ただし**履歴の記録だけは今から動く**。後から遡って作れないため。

## 設計の要点

### 教室は平面図シートのセルそのもの

机の位置と班の形をパラメータで表そうとすると、島型・コの字・変則配置のどれかが
必ず表現しきれなくなる。だから**セルに直接描く**。

| セル | 意味 |
|---|---|
| 空白 | 通路・空間。机ではない |
| `#教卓` のように `#` で始まる | 注記。机ではない |
| それ以外 | 机。セルの値がその席の班ID |

```
            #教卓
   A  A     B  B     C  C
   A  A     B  B     C  C

   D  D     E  E     F  F  F
   D  D     E  E     F  F

         G  G  G
```

これで A班4人・F班5人・G班3人という不揃いな班が、追加の設定なしで決まる。
班のサイズも班数も平面図が決めるので、設定項目にしていない。

**物理的な隣接は「上下左右のセルが両方とも机」のときだけ成立する。**
斜めは数えない（斜めの席は会話が起きにくく、関係の指標として質が落ちる）。
机の間に空白セルを1つ置けば隣接が切れる。通路をそう表現する。

### 履歴は席IDではなく生ログで持つ

`履歴` に「実施回・実施日・番号・席ID・班ID」を追記し、
`履歴_平面図` に同じ実施回の平面図を控える。
累積の隣接関係はこの2つから毎回計算し直す。

席IDだけを持つと、教室の形を変えた瞬間に過去の履歴が意味を失う。
年度途中で机の配置を変えるのはふつうにあるので、その持ち方は採らない。

### 印刷は白黒を前提にする

班の区切りを色の塗り分けで表すと、校務の印刷機（白黒が既定）で灰色の濃淡になり、
班の境界が読めなくなる。**班の境界は太線**で描く。

### 向きは回転であって反転ではない

教卓に立って児童を見る向きと、児童が黒板を見る向きは、上下も左右も逆になる。
上下だけ反転させると左右が入れ替わらず、教室と合わない座席表ができる。
`教師用` は `掲示用` を **180度回転**して作る。

### 名簿を外に出さない

- `UrlFetchApp` を使わない
- HTML から CDN を読まない（CSS・JS はすべてファイル内に書く）
- Web アプリとして公開しない（`doGet` を持たない）
- 共有はスクリプトを入れたスプレッドシート単位で、必要な範囲に閉じる

**既存の校務名簿ファイルに直接このスクリプトを入れないこと。**
他の教員と共有しているファイルがスクリプト付きになり、
名簿側の列構成が変わるたびに壊れる。新しいスプレッドシートを作り、
名簿シートに値をコピーして使う。転出入があったときだけ更新すればよい。

## 置き方

1. 新しい Google スプレッドシートを作る
2. 拡張機能 → Apps Script
3. 次のファイルを作って中身を貼る

| Apps Script 側のファイル名 | このリポジトリのファイル |
|---|---|
| `Code.gs` | `Code.gs` |
| `Layout.gs` | `Layout.gs` |
| `board.html` | `board.html` |
| `print.html` | `print.html` |

4. 保存してスプレッドシートを開き直す（メニュー「席替え」が出る）
5. 「席替え」→「初期設定（シートを作る）」

## 使い方

### はじめの1回

1. **名簿** シートに児童を貼り付ける
2. **設定** シートで `名簿の列:番号` などを実際の列名に合わせる
   （列は位置ではなくヘッダ名で引くので、並び順は問わない）
3. **設定** の `学級名` と `教卓の位置`（`上` か `下`）を入れる
4. **平面図** シートに教室を描く（上記のルール）
5. 「席替え」→「平面図の見た目を整える」で列幅・行高・班の色がそろう

### 毎回

1. 「席替え」→「配置ボードを開く」
2. 「名簿順に流し込む」で初期配置を作る（横順／縦順／班順）
3. 直す
   - 児童をクリック → 席をクリックで配置
   - 席をクリック → 席をクリックで入れ替え
   - 席を選んで `Delete` ではずす
   - `Esc` で選択解除
   - **保存ボタンはない。変更のたびに自動で保存される**
4. 「印刷へ」→ 4種から選んで印刷
5. 席替えとして確定するときは「席替え」→「この配置を確定して履歴に残す」

間違えて確定したら「直前の確定を取り消す」で1回ぶん戻せる。

### 印刷の4種

| 版 | 向き | 用途 |
|---|---|---|
| 掲示用 | 児童から見た向き | 教室に貼る。ふりがな付き・氏名大きく |
| 教師用 | 教卓から見た向き | 教卓に置く。番号＋氏名 |
| 番号のみ | 教卓から見た向き | テスト・配布物の仕分け |
| 白紙版 | 教卓から見た向き | 授業中の記録用。枠と番号だけ |

## シート

| シート | 中身 |
|---|---|
| `名簿` | 番号・姓・名・せい・めい・性別・分散タグ・タグ更新日 |
| `設定` | 学級名／教卓の位置／実施回／名簿の列マッピング |
| `平面図` | 教室そのもの。机のセルに班ID、空白は通路、`#` は注記 |
| `配置` | 席ID → 番号（いまの配置。ボードが読み書きする） |
| `履歴` | 実施回・実施日・番号・席ID・班ID（追記のみ） |
| `履歴_平面図` | 実施回ごとの平面図の控え |
| `制約` | 視力前列／分離ペア／固定席（次段で使う。入力は今から始められる） |

`分散タグ` は名簿の列だが、**印刷物には一切出さない**。
評価語（「しっかり者」など）を値にせず、配置上の役割名にする。
児童の固定的な評価を明文化してデータに残すと、目に触れる経路ができ、
教師の側の見方も固定される。値は `支え役` のような機能名にし、
`タグ更新日` を見て学期ごとに見直す。
